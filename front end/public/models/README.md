# Gojo 3D Model Directory

Place your custom licensed Gojo Satoru 3D model file here named `gojo.glb`.

## Supported Formats
- Format: Binary GLTF (`.glb`) or standard GLTF (`.gltf` with `.bin` and textures)
- Target filename: `gojo.glb`
- Recommended size: < 15MB for optimal web performance
- Recommended materials: MeshStandardMaterial or MeshPhysicalMaterial with roughness and metalness maps

If `gojo.glb` is not present, Esport Hub automatically renders a high-performance procedural 3D stylized character mesh with dynamic cursed energy lighting, and provides an immediate static artwork fallback for low-power devices and `prefers-reduced-motion` environments.
